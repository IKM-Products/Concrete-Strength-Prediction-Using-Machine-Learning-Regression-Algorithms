# 🏗️ Concrete Strength Prediction Using XGBoost and Random Forest

**Concrete Strength Prediction Using XGBoost and Random Forest** is a machine learning project focused on predicting the compressive strength of concrete based on its material composition and age. The project applies ensemble learning algorithms to analyze construction material data and generate accurate strength predictions for civil engineering applications.

## 🚀 Features

* 🧱 **Concrete Strength Prediction**
  Predicts concrete compressive strength using machine learning models.

* 🤖 **Ensemble Learning Models**
  Implements:

  * Random Forest Regressor
  * XGBoost Regressor

* 🧹 **Data Preprocessing Pipeline**
  Includes:

  * Missing value checking
  * Duplicate handling
  * Feature scaling/preprocessing
  * Data splitting

* 📊 **Feature Analysis**
  Uses material composition and age-based features for prediction.

* 📈 **Performance Evaluation**
  Evaluates models using:

  * MAE (Mean Absolute Error)
  * RMSE (Root Mean Squared Error)
  * R² Score
  * Cross-validation

* 📉 **Visualization Support**
  Compares predicted vs actual concrete strength values using graphs.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib
* **Models:** Random Forest, XGBoost
* **Development Environment:** Jupyter Notebook / Google Colab / VS Code

## 📂 Dataset Features

The model uses the following input features:

* Cement
* Blast Furnace Slag
* Fly Ash
* Water
* Superplasticizer
* Coarse Aggregate
* Fine Aggregate
* Age (days)

**Target Variable:**

* Concrete Compressive Strength

## 📱 How It Works

1. Load and preprocess the dataset.
2. Analyze missing values and duplicates.
3. Split the dataset into training and testing sets.
4. Train Random Forest and XGBoost models.
5. Evaluate model performance.
6. Compare predictions with actual values.
7. Select the best-performing model.

## 🎯 Objective

The objective of this project is to develop a reliable machine learning solution for estimating concrete strength, helping engineers reduce testing costs and support better construction decision-making.
